# R42 原始卡牌流程与人物身份纠错（隔离 Demo）

## 参考与规则边界

参考短剧：[《学渣决斗者》第9集](https://www.bilibili.com/video/BV1qFdcBqETD/)。
这是 AI 动画短剧，不是可验证点击顺序的完整游戏操作录像。只能参考“选牌、召唤/发动、人物登场、对手回应、攻击和结算”的表演语言，不能将影片中的设定冒充本游戏的三战线或按钮流程。

本游戏三条战线（教室、走廊、操场）和召唤后下次己方行动自动攻击，属于我们已经在用的原创规则，不是视频里已证实的规则。本版不擅改规则引擎。

## 严格交互规范

1. 首次点击卡牌只高亮并显示名称、费用与确认出牌按钮；不扣能量、不移除手牌。再次点击可取消，改选其他卡也不会误出。
2. 明确点击“召唤这张牌”或“发动这张牌”才真正出牌。
3. 召唤位置默认①教室。三个区域明确标在战场内（①教室、②走廊、③操场），卡牌下方也有同样的目标选择框。改区域并不立即出牌。
4. 只有按“结束回合 → 对手行动”，AI 才执行其本回合策略。界面持续说明 AI 实际出牌、目标位置，以及是否出现真实攻击。
5. E01/G01 真三维战斗使用主页 R22 同源的 Shino/Fumiriya VRM 源网格、原有配色及配饰；不再使用 R14 低精度替身。其他角色不冒充 E01/G01。

## 验收与边界

- qa/browser-r42-card-flow.mjs：桌面、手机、普通卡牌、改目标场景，真实规则与角色交锋测试。
- qa/browser-r42-selection-invariants.mjs：选牌、取消、换牌、切战场目标不改变规则状态，确认后才真正扣费及部署。

特别注意：本版只是孤立候选，并没有从视频证据证明现有自动攻击机制与原版一致；以后需要另行审查攻击宣告/效果触发流程后，才能调整核心规则。

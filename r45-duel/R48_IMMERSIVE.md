# R48 · 全屏三维体育馆与响应式镜头

## 本次实现
- 三维场景 100dvh 全幅铺开：卡牌、能量、HP、出牌和结束回合均作为响应式 HUD 悬浮在场景上方，不再在三维窗口下方堆积独立网页面板。
- 真实三维镜头：按当前 canvas 宽高比和视场角反算可容纳宽度；每次 resize 重新拟合，不再固定 z=8.7；21:9、16:9、4:3、竖屏分别经过浏览器场景投影检验。
- 左右出牌举卡投影和体育馆两侧操作台向中央收拢：5.05 / 5.55 世界单位；保留中央半径约 2.8 的唯一召唤战场。
- 拖动 WebGL canvas 以 0.27°/像素环绕场馆；按钮以 45° 递增（可到 ±180°），正面按钮回归 0°；滚轮缩放 0.84–1.65 倍；支持 ← → 和 Home/R 键；网页全屏按钮调用浏览器 Fullscreen API。
- 弧形平滑过渡，不引入镜头抖动；大角度绕场时移除阻挡视线的最近侧墙/背墙/看台遮挡，战斗对象与真实角色不变。
- 仅使用当前 R45/R46 资源；没有恢复任何旧运行时。游戏规则 engine.mjs 未修改。

## 验收
- `node r45-duel/qa/browser-r48-immersive.mjs`：2560×1080、1920×1080、1366×768、1024×768、430×900、375×667 六种比例，验证场馆全屏、两侧投影可见、45°/90°/180°/回正、真实出牌与 AI 应答。
- `node r45-duel/qa/browser-r48-pointer.mjs`：真实浏览器鼠标拖动，断言镜头角度变化与回正。
- `node r45-duel/qa/browser-r46-art-gate.mjs`：三组桌面/移动小屏旧版规则、角色和特效回归。
- 截图及原始 JSON 只保留在本地 QA 证据目录；不将大量临时截图混入公开网站。

# R79 原创魔法特效：真实卡牌场景接入与试验回执（2026-11-12）

## 核心决策
研发以游戏的最终视效、可玩性、人物和原画一致性为先：第三方效果好就学习其数学/渲染/时序原理；允许复用的源码可保留许可后复用；不适宜复用的资源不成为研发阻碍，直接独立实现同类能力并提升品质。本次特效模块 **不复制任何第三方项目代码、贴图、音效或角色**。

## 运行和代码
- 源：`r45-duel/scene/elemental-vfx.mjs`，原创 Three.js GPU ShaderMaterial 粒子、漩涡传送门（GLSL）、旋转法环、碎晶、陨石、雷电闪耀、地面符纹等，8种测试可交互预设；
- 精确对应真实游戏卡牌：`E01/G01` 召唤门；`E05` 增益；`E06` 陨石；`G05` 晶体；`G06` 符纹；`T05` 水环；`T06` 闪电；其他单位通用召唤门；
- 衔接 `r45-duel/scene/scene.mjs` 现有 `ASDC_R46_CARD_PLAY` 消息；使用 **游戏已经存在的同一个 renderer、scene、camera、人物、规则及出牌交互**，不运行第二个渲染器；
- 修正原 `card-holograms.mjs` 禁掉 `kind:'spell'` 导致的法术投影不能展示的问题；
- 效果是一组可跳过、会自动结束并回收的展示对象；没有权限也没有引用更改卡牌战斗数值/玩家手牌的代码。
- 不对现有 R78 工作区脏文件做任何读写覆盖；使用基于 R80 HEAD 的 R79 独立 Git worktree。

## 后续必须打磨而不是继续堆背景工作
- 把高精度角色的动作与漩涡光环精确同步：手部蓄力、开门、演员自然走出、冲击停顿、表情与收势；
- 提升法术粒子密度、弧线层次、能量尾迹、材质和物理接地反应，统一原画视觉风格；
- 每张实际卡牌的独立差异：不许全部只是同一个光圈换色；精确 3D 朝向/比例/地面、镜头限幅，模型必须达到动画电影级制作质量；
- 高画质与低画质自适应、p95 GPU/CPU 帧时与 draw calls；当前 Chrome 自动点击多次同时显示时累计 draw calls 约 600+，这包含整个体育馆和角色基线，并非单个魔法特效用量，需后续实测拆解；
- R79 分支不得自动覆盖生产页；视觉/性能和角色验收后才进入稳定版本。

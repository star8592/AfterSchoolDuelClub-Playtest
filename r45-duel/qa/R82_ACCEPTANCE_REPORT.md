# R82 对战音画一体化 · 实机验收（2026-11-12）

## 成果与来源

本轮在 R81 独立分支 `feature/duel-r81-impact-audio-score-seats-20261112` 增加真正的卡牌命中闭环、AI 施法与音画同步，不覆盖其他版本生产场景。不是用第三方施法项目的源码：所有本轮新 Shader/动画/椅子/SFX 均为本项目原创实现，人物继续复用经项目核查的已有模型。

- **引擎权威事件**：`engine.mjs` 在原本的 `card_play` 事件上增加 `spellOutcome` 只读摘要，精准记录 `directDamage`、`unitDamage`、`targetUids` 和 `healed`。没有新增规则伤害、卡牌或新的事件 serial。AI 连续出牌不再把总伤害误分配给某一招。
- **真实命中逻辑**：`scene/scene.mjs` 接收 `ASDC_R81_SPELL_RESULT` 后，仅在 `directDamage>0` 时让对方出牌者出现受击姿态，仅在 `targetUids` 命中时驱动在场实体的 hit 动作；无伤害技能不假装击中。0.46秒视觉命中点才播放受击反应，重击音效和人物痛呼也延后到近似同一帧。显示 HP 仍实时来自规则引擎，不反写引擎。
- **更强烈且真正不同的特效**：E06 黑板擦从施法方跨越整个球场飞向对手，末端产生有重量感的撞击和碎片；T06 是五路声浪线束与声压圈；G05 修复晶体、G06 翻页符阵、E05 能量助威、T05 暖汤护盾互不相同。这些是当前规则卡的效果，雷暴链/巨陨/冰封/巨潮等作为未来正式新卡才能增加对应策略，不能混为已经可打的卡。
- **角色主持人**：站在左右决斗台的人物原有高精度 VRM 保留，骨骼动作改为亮牌、抬臂、前倾施法、命中后退并恢复；动作与真实出牌信号绑定。仍需艺术家级动作、表情、口型和双人互动精修。
- **体育馆**：396个分件真实座椅（前看台198、反向198），带圆角座面、靠背、左右扶手、金属立柱/饰边，使用 instancing；移除旧彩色小方块，主屏用 1536×288 CanvasTexture 渲染真实引擎两方 HP、回合、连携，HP 20→17 高亮。
- **配音和声音**：14个召唤角色各2条入场/攻击，左右出牌者各2条出牌/受击，总共32条中文原创 Qwen3-TTS Opus/Ogg；已通过32条 SHA256/时长/格式验收，仍全部标记 **pending-human-listening**。额外新合成 8 个原创短音效，总17种音效与2段音乐；首次交互须用户打开声音。攻防对话不再同一帧互相抢占，大量同时攻击时优先选择一个代表性攻击呼喊。

## 验收回执

- `qa/browser-r81-impact-score.mjs`：Chrome WebGL seed=1，真实出牌 E01 手数5→4、召唤门、两位决斗者动作与396座椅；seed=5，E06出牌从20→17、真实 spell hit、对手后仰与3D大比分牌一致。0 JS/HTTP错误。
- `qa/browser-r82-ai-spell-events.mjs`：seed=8，AI 在正式回合打出 `G05`，`spellOutcome.directDamage=0`、角色不作假受击、HP维持20:20；真实 WebGL repair 效果触发。
- `qa/browser-r81-visual-audio-lab.mjs`：8按钮实际渲染，场景规则HP不动，测试语音文件的 Audio HTMLMediaElement readyState=4 且 `paused=false`。实验室演出不代表权威规则伤害。
- `qa/r70-validate-audio-assets.mjs`：32条语音、16角色名、17种音效、2段歌曲全部文件/Opus/hash验证；仍须人耳逐条表演审美复核。
- 引擎命令 `simulate(seed,'first')` 对 seed1..500 的500场比赛完成，另500局前8轮收集到1442条真实法术出牌事件，`spellOutcome` 字段校验错误0，日志原始总数13750。
- **真实无声录屏**：`qa/evidence/r81/r82-actual-eraser-versus-rival-silent.mp4`，1280×720、约5.96秒，直接录自 Chrome WebGL 真正打出 E06 的可玩游戏；音轨未被 Playwright 录制，声音请从实际网页体验，不得称视频自带配音。
- 对应测试 JSON 与截图都在 `qa/evidence/r81/`。

## 尚待验收 / 质量不足部分

- 人物最终高精度模型和完整动作演出仍需在真正可玩视频中逐卡验收；少数卡牌的表现暂为本轮基础效果，不等于各角色最终终极技。
- R81 音效声色是初版，32条语音已能播放，但需按角色身份检查发音、语速、节奏、与口型和施法动作同步。
- 真实 396 椅位已从平面方块升级为可辨独立椅子；仍需高画质近景确认座椅布局、厚度、透视比例、遮挡与整体材质。
- 没有经过大规模 GPU 性能 P95、长时间内存/热稳定性、S22/Pad 各平台验收；也未做跨分支整合到生产游戏或公网发布。
- 不复制原作的故事、人物和音频，技术效果可自行做得更好，无须因为第三方素材授权风险而停止原创开发。

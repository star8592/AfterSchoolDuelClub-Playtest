# R55: 18卡三维资产审查厅（非正式成品）

独立隔离艺术研究网页，不修改正式 r45-duel 的卡组、规则、引擎或召唤物路径。可加载源 VRM、CC0 GLB、历史物件 GLB 共12种人物候选，6 张事件牌各有可旋转的 3D 概念预演，不冒充高品质成品。

## 真实浏览器质检
- browser-r55-audition.mjs: 18卡 × 桌面和竖屏，36/36 Chrome GLB/特效加载通过。
- batch1/browser-batch1-angles.mjs: E02、T02、T01、G01 × 0/45/90/180 度 × 两种视口 = 32 张截图，32/32 非空白像素检查通过。首次 E02 两张照片由于 shader 懒编译出现白屏，已增加稳定渲染等待并复测消除。
- batch1/EXECUTION.md 和 worklist.json: P0 原画/来源、P1 三维候选、P2 美术动作、P3 场馆实战验收；本轮高品质角色正式美术验收数依旧为零。
- batch1/prepare_e02.py: 将已有 E02 透明图规范成 768px 图生 3D 输入，保存源图和输入 SHA、商业许可风险及 GPU 门槛。当前没有新 GLB 输出：GPU 空闲仅约 4.2GB，守门脚本拒绝占用其他任务的显存。

## 模型权属
- Gobkit 已下载的 13 个 GLB: 官方免费模型 CC0 1.0，可商用改造；来源 URL 和 SHA256 记录在 models.json。技术上可用作骨架和动画参考，低精度造型不得直接进正式游戏。
- E01/G01: 正式工程原有的 VRM 网格，保留原授权和现有文件路径。
- E02/T02: 项目历史实验 GLB，继续标为美术未通过。
- Pixal3D 图生模型: 尚未开始推理；权重包存在 DINOv3 另行授权条款，许可审核完毕前不商用发布。
- 6 张事件牌: 本审查厅中的 3D 概念技术预演，不是正式技能特效。

## 如何预览
在仓库根以静态服务器启动并访问 /r45-duel/art-lab/r55-audition/ 。点击卡片切换候选模型，拖动画布转动，滚轮缩放，使用 Idle / Attack / Walk 检查现有骨骼动作。

## 发布门禁
只有角色原画、三视图、完整三维材质、蒙皮、动作、卡面同源和浏览器不同角度截图获得明确的艺术验收，才允许复制到正式 assets 并改动 summon-presence.mjs。网页的 36/36 和 32/32 只能证明技术可加载、可见，不能证明品质达标。

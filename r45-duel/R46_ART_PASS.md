# R46 · 3D 竞技场美术深化（工程样机）

本轮只优化 R45 已验证的单一三维体育馆、角色舞台表现和卡牌视觉。
规则 engine.mjs 不变，正式出牌动作流程仍然是选牌 → 确认出牌 → 结束回合 → AI 回应。

## 已实装

- ambientCG WoodFloor045 1K Color/NormalGL/Roughness CC0 PBR：真实材质用于三维木地板，授权凭证在 assets/textures/LICENSE.txt。
- 物理看台安全栏、体育场围线、舞台投光灯、两端召唤台金属地标、实体悬挂横幅与赛场发光招牌，统一偏温木色加蓝金灯光。
- 原生三维角色的演员比例、微动态和低抖动镜头推进；E01 及 G01 的源 VRM 人物分别包含 148、107 根骨骼，不进行重新生成或混合替身。
- 真三维地面召唤光环、粒子与命中受击效果；视觉事件只消耗真实对局伤害，不修改规则。
- 两边决斗台从正确一侧投射对应出牌的三维卡牌牌面，包括 AI 自动出牌提示。
- E01 和 G01 的卡面肖像直接由对应原始 VRM 模型在本机 WebGL 实拍渲染，图像源存于 art/portrait-src，最终卡片在 assets/cards/；其他16张牌使用不同的临时标识并明确标记为未完成美术，不用无关人物冒充。

## 验收与限制

- Z890 RTX 5070 Ti / Vulkan WebGL Chrome 真实桌面、常规手机和小屏，经过端到端真实出牌、AI回应、E01 对 G01 战斗、伤害结算检验；见 qa/evidence/r46-stadium-art-qa.json。
- 实际截图在 qa/evidence/r46-*-opening.png 与 r46-*-impact.png。
- 这仍然不是终版美术验收通过。角色动作尚缺高品质演出，另外16张卡的三维召唤模型尚未完成，正式的左右决斗者也尚未有独立角色模型。
- 依赖为本仓库 r45-duel/ 内置 Three.js/VRM，不会链接已删除的 R14-R44 运行时。
- PC 性能优化仍需继续，当前3D交锋在 RTX 5070 Ti 上约300–400 WebGL draw calls，不代表低端设备可稳定运行。

## 运行测试

node r45-duel/qa/browser-r46-art-gate.mjs，使用本地独立 HTTP 服务指向仓库根目录（脚本默认 127.0.0.1:10976）。

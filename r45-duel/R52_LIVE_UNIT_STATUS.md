# R52 · 3D 单位血量、卡位与压力测试

## 已实现
- 游戏页面把已有规则单位的 UID、card ID、当前生命值、攻击力、护盾以只读快照发往 3D 体育馆。伤害、回合、AI 和胜负仍由原规则引擎决定，显示层不修改任何规则。
- 场内每个真实 VRM 或明确标记的临时召唤卡位，都有独立的面向镜头的 3D 世界空间血量标识。标识包含卡牌角色名、当前 ♥HP 与血条；只在数据变化时重新绘制纹理。
- 满场 5v5 时自动缩小血量标识，避免大型血量提示遮蔽人物。单个单位被击败后，标识随之销毁。
- 修正初始 E01/G01 VRM 在第 3、4 等非默认卡位时被动画强制搬回默认中央卡位的问题：非战斗时严格按真实召唤阵位显示；原 R46 专属骨骼交锋时仍保留动画位移。
- R51 普通交锋时读真实攻击事件中的剩余生命值更新提示；事件结束后从正式规则存活单位快照还原，既不漏删也不保留幽灵标签。

## 测试记录
- browser-r52-hp.mjs：1920x1080 / 430x900，10 个单位的血量标签、独立 UID、非默认卡位、伤害/治疗后血量变化和销毁，均通过。
- browser-r51-combat.mjs：种子 1 E02→G01 与种子 4 G02 直击等真实战斗，4/4 通过。
- browser-r49-regression.mjs：真实 VRM 专属战斗 3/3 通过。
- browser-r49-proportions.mjs：21:9 / 16:9 / 4:3 / 竖屏等 6/6，通过全部旋转及回正。
- browser-r50-roster.mjs：12 人物牌双阵营、重复同名召唤、5v5 满场与清场全部通过。
- browser-r52-performance.mjs：RTX 5070 Ti + Chrome Vulkan headless，1920x1080，2 单位实测平均 43.6 FPS / 369 draw calls；10 单位 44.1 FPS / 779 draw calls。该浏览器环境的 FPS 是当前参考基线，不是可移植到所有 PC 的性能承诺。

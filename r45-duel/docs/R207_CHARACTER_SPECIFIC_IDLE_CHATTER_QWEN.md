# R207｜《放学后决斗社》16类角色的随机闲聊与原声配音

**2026-11-20 · 基于R206的隔离 Draft · NO-GO**

## 设计与实现

- 16 类角色：两个站台玩家，以及14种当前真正可召唤角色 E01/E02/E03/E04/G01/G02/G03/G04/M01/M02/T01/T02/T03/T04。
- 每位角色新增2句独立校园荒诞喜剧对白；合计32条原创 Qwen3-TTS 1.7B 离线录音（48kHz Opus）。沿用原 manifest 的 Vivian/Dylan/Eric/Serena/Uncle_Fu 等角色配音身份，不使用浏览器 TTS 或远程生成。
- 对白文本统一维护在 r207-idle-chatter.mjs，离线生成脚本从同一数据源读取，保证字幕与配音原始文字相同。每条含完整 SHA-256、时长、原声角色、人工听感待审状态。
- 随机而不吵：正式对局首句至少开场14～24秒后出现，后续每26～42秒一条；最近有牌局事件需保持8.5秒安静；不连着让同一人物说话，同一人的两个版本轮替。
- 只让权威棋盘上存活的召唤角色及两位实际出牌者说话。其他未登场角色不会凭空出现。真正的角色攻击、受击、裁判广播、教学语音均优先于低优先级闲聊。
- 同一声音通道只允许一条闲聊，不叠加或排长队；用户静音、声音尚未准备、教程、比赛结束和后台标签页禁用。
- 950ms一次极轻量状态检查，无每帧推理、无联网TTS、无额外摄像机/灯光/渲染pass、无修改卡牌费用HP胜负逻辑。
- 必须通过 r207Chatter=on 显式启用；默认关闭，且 r207Quick=on 仅用于 qa=1 测试。

## 真实测试

- 资源测试：16/16 角色、32/32 真正的本地Opus文件、32/32 SHA校验通过；配音文案与字幕精确一致。
- 原始Chrome WebGL2真实竞技场：自然定时选择不同角色实际播放原声，字幕显示与浏览器播放回执相符；无规则事件、HP、回合变化；游戏依然全场广角。
- 独立真实录音 M01 音乐老师字幕抽查通过；默认关闭后播放入口不可用；浏览器 JS/HTTP 错误0。
- 真实证据目录 qa/evidence/r207-idle-voices：含22.64秒六角色可听试听合集、两张原生Chrome字幕画面、完整回执报告。

## 发布边界

本轮只实现现有16类配音人物的闲聊，保持原高精模型及旧配音不动。当前32段录音已通过原始媒体真实性与浏览器播放验收，但仍待人工听感和表现力签收；未证明低配设备冷加载或长期帧时间的改善；源人物若没有真实口型网格，不声称已经实现口型同步。严格 Draft / NO-GO，不合并 main 或改动正式R198。

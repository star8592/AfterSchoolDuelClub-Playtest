# R205｜真正让牌里召唤出来的人物活起来：七名高精学生解除“僵尸站桩”

**2026-11-20｜《放学后决斗社》PC优先｜基于R204 Draft｜R205仅在实验URL开启，NO-GO**

## 用户亲眼指出的问题

R202–R204 已把“施法者举牌猛甩—校园道具撞人—对手被打有反应”做得更有趣，但卡牌召唤出的 3D 人物在入场之后仍会举着胳膊僵住。尤其七名旧 R97 真人学生，继续叠加不可见骨骼的旋转代码并不能解决问题。

### 本轮找到的实际根因

对七份原始 `Landing-R97.glb` 逐个读了真实 GLTF 数据：
- E03、E04、G02、G03、G04、T03、T04 **每份都带有一个原始皮肤结构，却没有将实际渲染的身体网格绑定到该皮肤上**。这意味着以前一些“转肩膀/挥手”的动作更新的是**不控制人物皮肤的空骨骼**。
- 可见的身体、头发与服装实际上有 Blender 作者已经做好的 **六种原生形变目标**，按网格分布为 `Step`（迈步）、`Strike`（出击）、`Brace`（防御）、`Land`（落地）、`Recoil`（受击）、`Retreat`（后退）；不能假设每一块网格都有全部六种，必须检测实际索引。
- 默认有 `Idle` / `Attack` / `Hit` 三条原动画，它们大多也是修改 morph 权重而不是有真实全身骨架关键帧。过去额外赋值的幅度很小，入场以后观众仍看到手臂停住。

因此本轮**没有重复启用R119–R146那批出现过贴图失真、骨骼扭曲的研究模型**，没有重新绑定骨骼，也没有更换用户满意的原始高精外观。只直接驱动**每份原始渲染网格已经拥有的动画形变目标**，让游戏里真正看到的身体动起来。

## R205边界和下阶段选择

本次解决的是**R97高精原模型内既有六组可见身体形变利用不足**。这些GLB的实际可见身体没有皮肤绑定，**不可能凭空拥有完整的真正关节奔跑、转身、踢腿等自由动作**。要实现更电影级的全身自然演技，需要将每名原角色正确绑定真皮肤骨骼或取得同质量带绑定的源模型，并逐一做贴图、原始脸、脚底、肘腕动作、回位、反向朝向的可视化验收。不能重启未经验证的旧 R146 变形模型。

下一轮重点仍是：先让玩家验收这批实际动作镜头，再对仍显生硬的具体角色逐个改善带皮肤的源模型、动画与场景调度。除此之外还需处理XPS的冷启动与多版本缓存一致性问题。

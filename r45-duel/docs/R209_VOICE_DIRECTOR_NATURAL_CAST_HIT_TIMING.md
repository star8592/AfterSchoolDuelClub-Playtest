# R209｜实战配音导演：解决施法台词在命中瞬间被截断

**2026-11-20 · 《放学后决斗社》 · 基于R208的独立Draft · NO-GO**

## 1. 已由真实Chrome量化重现的问题

S08愤怒售货机真实手牌施法：原始3D汽水罐命中对手、权威结算2点伤害。R208虽然使施法口令与被击语音都能开始播放，但是在实际撞击时，音频引擎把原女玩家施法台词立即截断：

- 施法源录音 **2.81秒**；命中前只播放 **1.051秒**，剩余约1.76秒永久丢失。
- 不是缺素材，不是音色或嘴部动画问题，而是高优先级hurt在同一音轨抢占播放导致的。
- 日志取自真实Chrome/原游戏规则和原GLB，非推测；不把start事件误报为complete。

## 2. 精简双层表演修复

**R209用原有真实声音轨，没有重造整个音频系统。**

1. 来源为真实R208源GLB施法语音且将由对手受击时，如果施法台词剩余时间在0～2.5秒之间，当前caster主声道继续播放至结束，原受击者完整吐槽保留在**最多3条的优先队列**中。
2. 在真正的源GLB接触事件，同步播放受击者新录制的**短促真实Qwen惊叫**（原女玩家Serena“哎哟！”时长0.73秒、男玩家Dylan“哎呀！”时长0.57秒），声音约为常规人物语音音量40%，同时施法者声音短暂降至72%，惊叫结束后恢复，不让两个声音长时间互抢。
3. 原有真实撞击Foley与身体碰撞动作**完全不延后**；只有较长的完整受击吐槽排在施法结尾，形成“施法喊招→真实命中和短叫→对方吐槽”的轻喜剧节奏。
4. 同一源施法中重复的hurt事件归并一次，避免受击被重复排队；旧idle/enter/social低优先级陈旧语音可清理。长达3秒以上的延迟不采用，保持原受击优先，防止受击者等到下一轮才说话。
5. 仍沿用全场单次真实Chrome/WebGL2渲染，不新增光环、摄像机、口型系统、每帧AI、音频合成或网络TTS；原有保留的食堂阿姨动作及M01原创骨骼不改。

**安全开关：** 只有同时明确开启 r199PhysicalMagic=on、r208Audio=on 和 r209VoiceDirector=on 才使用R209导演。默认关闭。新Qwen短惊叫manifest只在实验开关开启时获取，音频仅命中时按需加载，对未开启者不额外下载。

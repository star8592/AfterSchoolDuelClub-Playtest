# R200｜真实 3D 校园魔法的清晰度、物理表面和拥挤演出优化（PC Draft）

**2026-11-19｜R199 的后续独立开发分支｜不合并正式 main，不发布默认玩家**

## 为什么有 46 种法术却仍然不够好看

前一轮实机截图证明 46 个真实 Blender GLB 都能演出，但个别道具在宽屏场景里的屏幕轮廓过小；连续施放时，先前的道具与新道具会堆叠。它们也只有 Blender 的基础 PBR 材质参数，全部 46 份原始 GLB 没有嵌入贴图。单纯把整段战斗镜头拉近会挡住对手受击反馈，故 R198 **永不自动特写**继续作为硬约束。

R200 目标是：保持完整原版人物、场景和镜头，仅提升一部分已经验证的道具的可读性和真实表面层次，始终能看见两边对战者。

## 本轮实质改动

### A. 五种真正贴图版本，不改原始网格

针对 **E06 飞来的巨大黑板擦、K01 茄子炒香蕉、K07 果冻蛤蟆布丁、Q05 粉笔记者会、P07 黑天鹅冰场**，新增可回退的 `_R200.glb` 版本；原始 GLB 原样保留，开关关闭仍然加载原版。

采用离线、固定种子的 128×128 PBR 微表面纹理：根据模型原材质名称，生成小幅度颜色起伏和表面粗糙度变化，例如金属拉丝、木纹、粉笔孔洞、食品表面细粒；每种材料由自身已有 UV 支持时才加载，**没有UV的主体表面绝不假称已贴图**。无新增点光源、ShaderMaterial或逐帧生成纹理，纹理 PNG 直接封进 GLB 供浏览器缓存。

五个变体增加 **56 张微贴图、总计约 375 KB GLB 文件体积**；源 GLB 的所有原始二进制顶点/网格数据字节、节点树、材质颜色和金属/粗糙系数、皮肤及动画定义，已运行独立字节级核对并确认不变。实际具有可贴图UV的材料数分别为 **4、5、8、6、5**，仍有部分道具表面缺乏UV不能覆盖。**这还不是全部 46 种道具的高品质贴图完成版。**

使用 `r199PhysicalMagic=on&r200Pbr=on` 才激活材质变体；普通玩家和原 R199 都不会被静默替换。

### B. 真正宽镜头下的道具可读性

测得原 E06 黑板擦在 1440×860 Chrome 场景中，屏幕包围框约 **148.5×106.8 px**。因为试验中黑板擦翻转过猛，曾一度只剩 121 px宽，遂改成略增大真实道具本身、让黑板擦保留大面积面向玩家的飞行翻转。最新 E06 约 **216.3×149.7 px**（动画阶段与渲染时刻不能完全锁定，两组数字是可读性证据，不是严格的像素同帧差异）。相机位置/FOV/镜头特写与对手完全不变。

其他已经占画面宽度约 18–21% 的大型道具（锅、蛤蟆、黑天鹅等）**没有无脑统一放大**。当新法术发生时，前一个演出道具在约 260ms 内小幅缩小退出，再由新道具完成完整演出，避免几个巨型道具重叠在同一个画面；不修改规则出牌顺序或结算数据。正常道具完整演出可持续约 2.5 秒，独立物件的已有角色动画（青蛙跳、黑天鹅动、锅中食材蹦跳）仍由原程序驱动。

**R198 禁止自动特写保持不变；没有第二台画中画摄像机，没有大卡图挡人，没有用旧光效替代真实道具。**

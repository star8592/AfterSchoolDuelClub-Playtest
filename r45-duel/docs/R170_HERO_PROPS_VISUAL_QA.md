# R170｜七种校园荒诞法术：实体道具精修第一轮

2026-11-18；隔离于R169的美术实验，**Draft / NO-GO**。

## 具体落地

在已有46张校园魔法独立实体演出的基础上，单独手工组合七套多部件材质道具：
- E06 厚重黑板擦：深色板擦、木质/金属外壳、装饰铆钉、大小粉笔碎屑。区别于轻飘飘的白球。
- K01 食堂茄子炒香蕉：实体炒锅、弯香蕉、烤茄子与菜粒。物理形态而非食堂发光圈。
- K06 火山辣椒奶茶：大奶茶杯、珍珠、吸管、辣椒、冒出的食材颗粒。
- Q05 粉笔记者会：讲台、双话筒、粉笔主持人、粉尘。
- P04 体育老师超级口哨：巨型金属哨体、口、孔、挂带以及声压装饰。
- P05 排球误入篮筐：排球缝线、篮板、篮筐、篮网支撑，能够看出跨项目误投。
- X05 作业本宇宙：中央作业本、11张飘飞的不同纸页和板书线条。

全部只用缓存几何与PBR Standard材质、没有新增PointLight/自定义Shader/纹理大包，不触碰人物和战斗数值。

## 本地验收与不足

46/46实体魔法WebGL渲染通过；16种重点截图，Chrome错误0。三组真实战斗（桌面新模式、手机浏览器视口新模式、桌面旧系统回退）都通过，原16个源模型、60卡、75,569,762字节资产保持原样。

七种Hero的多部件原型让真实单张最大绘制调用达到 **48**（R169旧程序化原型约12），这是新增的GPU负担，**不能据此宣称性能优化**。未来必须将大量装饰碎屑、篮网、纸张通过 InstancedMesh 合并，并用Chrome GPU timer与真机Android确认p95/p99不存在回归。

实际图片见 `qa/evidence/r170-hero-props/r170-seven-cinematic-props.jpg`。这一批仍是程序化立体原型，不是动画电影级精模：需要更好的三视图道具建模、材质细节、动作轨迹、手部握持、对手表情/动作反馈，以及真正的专属人物配音。

不得因为原型测试通过而合并上线。播放器继续默认旧R147安全版，所有R170变更QA隔离。

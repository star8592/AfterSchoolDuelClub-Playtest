# R206｜音乐老师 M01 的 T 字手修复：从僵硬平举到真正指挥、进攻、受击、恢复

**2026-11-20｜《放学后决斗社》PC优先｜隔离 Draft / NO-GO｜直接基于 R205 PR #185**

## 用户指出的问题

音乐老师平时像 T 字手，臂膀平举站桩；她应该即使不攻击也有自然、带性格的音乐老师指挥姿态，进攻要有明确发令和强烈表演，受击后还能自然回位。

本轮只修 M01 的原始源模型动作，不推翻已经得到肯定的施法者出牌动作 R204、道具砸人 R203、以及 R205 已验收的另外 13 个召唤单位。**没有自动放大特写。**

## 根因：原模型不是没骨骼，而是源 Idle 过分伸展

对 `M01-MusicTeacher-PolyforkSchoolTeacher.glb` 实际解析：**10个真实绑定皮肤的可见网格、31根真正驱动身体的源骨骼**；原 GLTF 已有 `Idle / Walk / Run` 三套原生动作，且原 Idle 包含 **23 条骨骼轨道**。之前 R126 又叠加四套真骨骼指挥、命令、受击、欢呼动作。但是原始 Idle 的双臂展开幅度太大，而附加指挥动作多数只有0.1–0.4弧度，未能纠正你看到的平举感。

**不是通过替换低模、扭一个假骨头或把整个人摇晃来修。**

本轮在原来的 `AnimationMixer.update` 之后，直接测量**本次真实姿势的肩→肘→腕方向**，将真正的 `LeftArm / RightArm / LeftForeArm / RightForeArm` 向预设的音乐老师动作意图安全调整。目标向量跟随**原人物模型的世界方向**，不是固定对着镜头。原骨骼、原皮肤、原贴图、原混合动画、原规则都不替换、不改变原 GLB 文件。肩/前臂每次修正各限最大1.36/1.20弧度，防止乱拧360°。

## 新版 M01 的五种状态

- **待机：** 左臂放下、略弯曲，手收在腰/胸前；右手位于身前，主动打拍子、缓慢改变高度和角度，身体仍保留原音乐老师的脊柱/头部微动。连续循环中含准备、指挥、强拍，不再停成定格姿势。
- **进攻：** 右臂明显抬起，像指挥全体乐队发起最强拍；左手辅助发令。仍使用真正的原骨骼 `R126_M01_Order`。
- **受击：** 原本张开的手臂收回来抬手护脸/胸前，原 `R126_M01_Shocked` 同步表演。
- **恢复：** 原人物回到左手下放、右手打拍子的自然姿势，不再回到平举的 T 手。
- **行走与欢呼：** 保留原生 `Walk` 和欢呼原生源骨骼动作，额外约束手臂自然摆动与指挥谢幕。

R206 的所有改进均通过 `?r206MusicTeacher=on` 明确开启，正常网页/正式 R198 默认不启用。录制的实验画面没有换摄像机、演员模型或灯光；食堂阿姨 M02 的原生动作从头到尾不变。

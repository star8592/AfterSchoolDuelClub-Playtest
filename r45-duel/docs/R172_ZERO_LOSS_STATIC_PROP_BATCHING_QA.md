# R172｜校园魔法道具不降质合批验收

2026-11-18。分支独立于R170美术、R171音效。**QA环境技术通过；商业和真实手机性能仍是Draft / NO-GO。**

## 缘由

R170把7张标志性法术的3D实体细节增加后，每张法术最高从R169的12次 draw call 上升到48次。这不能当成“质量更高所以不必优化”。玩家明确要求不减少画质、避免魔法首次施放卡顿。

## 如何实现

- **不使用 InstancedMesh**；它会触发不同Shader define，可能增加首次Shader链接延迟。
- 对不独立运动、不透明、拥有相同材质和相容顶点属性的**同一个父组下的静态Mesh**，执行三维矩阵烘焙与`mergeGeometries`，用一个普通`THREE.Mesh`代替多个Mesh。保留所有面片与原始PBR材质，颜色、角度、镜头和DPR全部不改。
- 角色骨骼/VRM、动态道具、角色命中反馈、位置动画、透明素材、不同材质的网格一律不合批。
- 几何按魔法ID+场景父组+材质键缓存，避免重复施法时反复创建BufferGeometry；退出时显式释放。
- 只有双重参数 `?qa=1&r169SchoolMagic=on&r172BatchStatic=on` 生效；关闭R172或R169可分别回退。正式R147不改。

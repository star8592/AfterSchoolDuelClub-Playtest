# R75 · 不修补低模，直接使用可动画的高质量授权基板

**状态：候选模型和动作引擎技术验收完成；尚未取得原作逐帧真实画面，角色艺术匹配不通过，正式 13 角色不替换。**

## 资产采购与研发

- 已核对 [Microsoft Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox) 官方仓库的 MIT 许可证和包含表情/多边形 LOD 的源头像库；已下载源自 Rocketbox 的 [CodeLove 3D](https://models.codelove.in/) GLB 和原生骨骼动画。所有 GLB 保留内嵌 `asset.extras.licenseText`、SHA256、源 URL。当前批次 10 件新增 MIT 原始角色模型、15 个原生 MIT 动作 GLB，总计 25 个二进制源文件。另继续复用 R74 三名原始少年/运动员候选，并补入第四个新女孩模型。
- 新增的 10 件覆盖：女厨师（食堂阿姨参考）、成年男性 2、成年女性 2、男性体育运动员 2、女性体育运动员 2、女学生 1。另 R74 原有两名男学生、女学生 1、体育员 1。
- **纠错**：R74 “女孩横躺”不是原始 GLB 缺陷，而是转换管线导入/导出 Y-up/Z-up 时造成的错误。R75 直接使用原 GLB + Meshopt 解码，四名儿童源身高均 1.42–1.44、全部真实站立，**源模型无损保持、没有修几何**。历史 R74 的错误判断不能再作为淘汰该模型的艺术证据。
- 成人原生动作骨架 `Bip01_*`，儿童角色 `Bip02_*`。在浏览器对 60 余条命名通道逐项转向/过滤，儿童 59/59 或 62/62 动画通道成功匹配；成人 59/59 或 64/64。动画动作来自作者原生数据，不是程序化“僵硬手臂 pose”。
- 原生动作涵盖 Idle / Look-around / Talk / Cheer / Clap / Wave / Walk / Dance 的男性/女性对应文件。候选试镜使用 15 个实际下载并校验的原 GLB，UI 公开 Idle / Talk / Cheer / Clap / Wave / Walk 等已具备性别对应文件的动作。没有可用单独的儿童原生表情库，后续如需脸部演出应另检源模型表情形态键和许可。
- 所有新模型都来自 MIT 授权的原始人物资源，仍需二次确认从源库到下载镜像的完整 provenance、避免把非原创影视 IP 的造型误当授权；**技术合法初审不等于正式角色艺术验收**。

## 三维演员试镜与现实镜头

- 独立网页：`r45-duel/qa/r75-native-character-casting.html`。可按「儿童/体育/成人/食堂」切换 4 套模型；选择自然待机、交谈、欢呼、挥手、鼓掌、行走；0/45/90/180° 姿态；切换干净试镜空间或者直接放入真实 3D 体育馆。人物不会替换游戏内官方 E03/G02/T03 等角色，避免错配。
- GPU QA：`r45-duel/qa/browser-r75-native-cast-motion.mjs` 用 Chrome + NVIDIA Vulkan + 禁用软件后备，实际 14 种 `[群组、动作、角度、环境]` 组合，每组四个独立原生 GLB，共 **56 次源人物动画场景检查，14/14 场景通过**。验证骨骼 79+、模型站立真实高度、轨道匹配率大于 75%、实际骨骼关节运动、WebGL canvas 非空、无 4xx 和 JS 错误，证据和截图在 `qa/evidence/r75/`。
- 附加静态源文件签名验证：`qa/r75-source-asset-gate.py` 对 25 件新增源文件逐个检查 GLB 魔数、容器长度、三角面、蒙皮、动画通道、嵌入 MIT 许可及 SHA256，生成 `qa/evidence/r75/native-source-report.json`。
- **旧游戏退路仍保留**：R75 未更改 19 卡游戏规则和 13 卡模型注册；R74 场边相机与 E01/G01 双决斗者常驻镜头、同角色召唤独立性继续通过。此前 Qwen3-TTS 14 音频剪辑已通过文件校验。

## 美术匹配判断（当前不虚报）

| 原作品角色类型 | 本轮优质原型候选 | 初评结论 |
|---|---|---|
| 校园小男生/加油队长 | 两位小男孩 Rocketbox 源模 | **可作为骨骼/人体底模**，但写实比例与原作漫画夸张风格尚有差距；还不能替换 E03 |
| 音乐老师 | 已被用户认可的 Polyfork School Teacher (R72) | 继续保留 M01；本轮优先找其成熟高模/现成服装动作，不做旧低模无意义微修 |
| 食堂阿姨 | Rocketbox Female Chef (真实厨师服装) | **角色职业贴近**但身体形态太瘦，不符合“全身圆润粗壮、肚子不过分突出”；暂不替换 T02 |
| 体育老师/体育委员 | Athlete 男/女职业系列 | 专业身份相符，但是否具备夸张动作、合适年龄和脸型尚无原作画面证据；先为后续二筛保留 |
| 黑板密码专家 | Adult Male / 职业模型 | 通用成年男性仍不是黑板密码专家；不替换 G02 |
| 默契收发员 | 本轮未选到合格双人完整人物资产 | T03 原配送员仅是兜底，后续找二人一组或两位同风格高品质职业底模，不修旧模型 |

**艺术淘汰新规则**：绝不以三角面数、是否带骨骼、是否成功加载为匹配“原作”；每一角色须有同源原作视频参考截图/三视图，在同机位对照脸/发型/身材/衣物/手型/原生动作，通过后才能更新 `art_approved=true`。原作视频 B 站公共 API 在本轮返回 412；在没有可核验画面时，不凭臆测给“原作相似”评分。

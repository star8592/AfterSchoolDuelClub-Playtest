# 放学后决斗社 R45 — 全新单场地正式研发主线

这是全新游戏运行时，不是旧 UI 叠补丁。

## 运行结构

- 唯一玩家入口：r45-duel/index.html。只有一个中央三维竞技场，不存在教室、走廊、操场三战线以及切换战斗页面。
- game.mjs、ui.css 是全新设计和编写的单屏游戏操作层；engine.mjs 是独立确定性规则引擎；scene/ 是真正 WebGL 3D 场馆和可动画人物渲染，视觉不修改规则。
- 运行所需 Three.js 和两套 CC0 VRM 原始资产已经复制到本目录的 assets/。**没有任何旧 R 系列目录的运行时依赖**。
- 双方在左右两侧的决斗台面对面出牌；中央为召唤战场；屏幕下方始终可见手牌、确认出牌、结束回合。
- E01 vs G01 的真实角色动画由规则引擎的 exchange 事件触发；伤害和反击由规则引擎一次性结算，无二次扣血。
- 开局直接显示三步新手教学，说明也在同一屏幕里展开。

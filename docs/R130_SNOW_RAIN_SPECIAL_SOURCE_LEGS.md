# R130 · 最后两名高精人形角色的真实下肢骨骼动作

2026-11-13。唯一 main 基线 R129 db97927。默认生产仍使用经过镜头和材质验收的 R97 高精模型；本轮是可回退的 R119 原生蒙皮研究，不强制默认更换。

## 五人平铺骨骼与两人特殊骨骼不能混同

真实解析所有 R119 原 GLB joints/parent：
- **G02 Snow / 黑板密码专家**：左右脚各有原生的 DEF-Thigh_1→DEF-Thigh_2→DEF-Knee_1→DEF-Knee_2→DEF-Foot→DEF-Toes 完整六层链，不重新连接，只新增真实人体站姿、迈步、受击、后退和恢复动作的8个源骨骼轨道。
- **T03 Rain / 默契收发员**：原大腿是 Thigh1→Thigh2，小腿是 Shin1→Shin2，脚和脚趾是两个独立的兄弟节点，三部分独立挂到 RIG；本轮只通过原 Object3D.attach 补连 Thigh2→Shin1、Shin2→Foot、Foot→Toe，保留原来源蒙皮、所有顶点、原纹理和 inverseBindMatrices；左右骨架重连后每个源关节 world bind 姿态漂移小于 0.00001。

两名演员分别以 Snow .79、Rain 1.24 的控制强度生成七段现有 R119 真实源动画的8条下肢轨道，保留真实原肩肘/脊柱/头部原剪辑，不复制食堂阿姨的动作个性。

## 工程隔离与回退

仅显式 r119Rig=G02,T03&r130Body=on 时启用。r130Body=off 恢复未经修改的旧 R119 源模型；普通不带 r119Rig 的玩家仍加载正式 R97 两人，避免未经美术验收就扩大默认下载和影响进局体验。R128 E04、R129 E03/G03/G04/T04 的独立研究开关不被覆盖。

## 真实可见变形证据

QA 不是动画条数统计。每个实际可见模型都从 source SkinnedMesh 的 JOINTS_0、WEIGHTS_0 选取真正受驱动大腿/膝影响、权重 >0.35 的源顶点，每帧用 applyBoneTransform 计算**真实源蒙皮几何**位移；同时读原生实际脚掌相对于模型的空间运动，避免模型整体晃动冒充脚踝。

Z890 Chrome 实测 R130 Snow/Rain 原版/研究版×桌面1440/竖屏430，**46/46**：
- Snow 实际腿部顶点最大位移约 .080–.082，脚部位移 .080–.083 模型局部单位，腿骨最大约 .169–.174 rad；
- Rain 实际腿部顶点最大位移约 .077，脚部位移 .089–.090 模型局部单位，腿骨最大约 .185 rad；
- 原生绑定、外观源、正确对手朝向、游戏规则HP不变、恢复待机、旧版回退、JS/资源缺失均核验通过。

## 关于“木棍感”的真实剩余工作

**R128–R130 完成了七名原高精模型的真实下肢驱动研究，不等于七名角色正式版全都改好了。** 近景中双脚接触地面、连续关键帧动作的力度、手指、发丝、衣摆穿插和每人独立性格仍需以 M02 食堂阿姨为参照进行严格的人工艺术验收。必须逐角色取五个状态：出场/待机、发牌与攻击、命中受击、胜败庆祝、退出复位，进行分镜连续帧与实际手机画面对照。未通过不得默认启用。正式场景/规则/音频/版权/高精原模型必须保留。

# R127：原猫头鹰模型的真实羽毛、眼睛、尾羽动作

日期：2026-11-13，基线 main R126 5e8474a。

## 原始模型实测

T01 Innerscene Owl R84 为129个独立真实网格、0 skin、0原始动画 clips。Blender 5.2.3 读取原文件网格边界，发现：
- 左右每翼 1 个 foundation、14 个 covert、14 个 flight feather，各29个真网格
- 左右眼各3个真实原件：虹膜、瞳孔与眼睛高光
- 两侧头羽各3个独立网格，尾羽8个独立网格
- 鸟躯干与头骨仍是连续几何，因此**当前尚不具备独立真实头颈骨骼**；不能宣称转头已完成

## 实施

加载后在原来源 Owl GLB 场景内构造翼根铰点，直接收纳已有29件翼羽，左右同步对称扑翼；眼球原网格有小幅凝视位移，头羽和尾羽有独立表演。保留所有129真网格、原材质、原模型大小、游戏规则和音效，没有新低模或额外模型下载。QA 使用相对鸟体的真实羽尖顶点位置测量运动，杜绝演员整体走动冒充翅膀变化。

按 idle/walk/attack/hit/celebrate/defeat 控制各自的预备和恢复，prefers-reduced-motion 自动降低幅度，参数 r127Owl=off 一键恢复旧R126动画。新动作只由游戏原事件驱动，不产生 HP/卡牌规则改变。

## 验收与限制

Chrome 桌面+430px竖屏：原129模型保留、两翼各29真网格、双眼各3和尾羽8、真羽尖顶点位移、零规则修改；回归 R120 58/58、R124真实出牌18/18、R123看台30/30。
独立头颈与眼睑闭合、真实带权重的翅羽骨骼仍需要后续美术工程；初步真实网格可动不能代替人工逐帧审美验收。

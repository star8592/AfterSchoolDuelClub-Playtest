# R104 · 竞技场相机和人物正面朝向恢复

日期：2026-11-12。代码基础为正式 R102 主线 da07182；本次仅修复演出视角、模型朝向和对应 QA，不修改牌池、伤害、配音、模型文件、召唤机制或 R103 卡面新 UI。

## 用户直接报告与实际根因

1. **俯视退化**：原场景镜头 update() 强制将桌面高度设置为至少 8.35，观察点只有 y=.68，距离约 10，导致从上方俯看体育馆；无论入场还是战斗，人物体积和脸部表情被压缩成小图标。
2. **14 种角色的“背身/侧背”问题**：R99 侧向 QA 门槛要求面向对手 dot > .95，间接把所有人强制转到与观众视线相差 72° 的近纯侧面。用户从正面观众席看，实际看不到角色正面。R104 将正面观众可见度提升到 cos(.655)≈.793，仍然保持 sin(.655)≈.609 朝向对手。
3. **降低视角后原站台人被截断**：站台实际位置为 x=±5.55，旧镜头只按 ±4.45 拟合，人物完整模型发生侧边裁切。R104 镜头自适应 fit 半径增加 30%，并通过每个真实 VRM 身体八角包围盒检测“两位决斗者完整落在屏幕内”。

## 已实现

- 桌面前排观众镜头俯角约 15.64°；手机约 14.31°，按真实 viewport aspect 与 orbit zoom 动态确定高度。原旧角高度只供回退，不默认使用。
- 人物角色 yaw 继续根据每个模型的 SOURCE_FRONT_YAW 分别校准，包括 T01 的特殊来源正面方向；我方、对方分别产生 ±0.655 角度，不简单进行统一的 180 度反转。
- 原有 45° 转镜头、回正按钮、减弱动态效果、连续 R90 战斗与 R102 小剧场保持独立。
- 仅供紧急回退/对比：正式对战 URL 追加 ?r104Camera=old 可以恢复旧 R49 高摄像机；?r104Facing=old 可以恢复旧 R99 近侧向角色面对对手配置。**默认不使用旧版**。
- 检查自动化测试旧阈值：改为检查对手可见朝向 dot > .60，玩家能看见正面 dot > .79；R49 相机 QA 不再把 cameraY>6.5 当成好画面的硬门槛，而改为真实人类眼平近景俯角和 VRM 完整构图。

## 真正的验证

- 新 r45-duel/qa/browser-r104-frontal-camera.mjs ：桌面 1440×900 与竖屏 430×900，14 种人物 x 两侧，分四组显示，实际 3D GLB/VRM 加载、合法来源朝向、人物完整入镜、无 JS 和 404、45° 旋转及回正。最终 64/64 通过、0 浏览器错误。
- 旧 R99 check-r99-chef-voice.mjs：146 条素材及 98 条配音 SHA、实物厨师帽/锅铲、朝向静态门槛全部通过。旧 R62 28 个双侧方向断言通过。
- 修复是在真实 source GLB/VRM mesh 上进行 3D 镜头/骨骼朝向，没有用新的替身角色或纸面贴图冒充。

- 尊重用户静音和系统降低动画效果；切换教学章节时清理暂存特效和镜头。

## 端口假阳性防范
第一轮尝试 127.0.0.1:11174 时，该端口已由别的 R124 旧工作树占用；首次成功测试不能作为主线整合证据。已作废首次成绩。实际重验改用 127.0.0.1:11284，执行 ss -ltnp、/proc/PID/cwd 以及 HTTP 内容里新教学 UI 的核对，证明服务工作目录正是 after-school-duel-r124-main-convergence-20261113。R123 的 Playwright 脚本新增 #guided-launch/#guided-words 的身份硬断言，防止误连旧工作目录。

## 发布与限制
该分支是在 main 基础上的新增逻辑，候选整合 PR 不等于已部署。原有四名学生的 FK 头、手臂骨骼无法全部匹配，表现含真实模型整身姿态替代，但不得对外说成独立骨骼完备。AI 配音与其他素材仍需人工听审、商用权利审核。后续音乐老师、食堂阿姨及更多 3D 观众群演须独立限额测试，避免增加过多 draw calls。

回滚仅需 revert 本次单独整合提交，不影响主线已经合入的 R120 / R121 / R124 战斗和性能优化。

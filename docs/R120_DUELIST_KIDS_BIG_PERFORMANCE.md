# R120 · 小朋友校园决斗：主角真的要举牌、甩牌、跳起来庆祝

## 问题与交付
以前两名正式独立 VRM 发牌者站在两侧演动作很温柔，真实右手腕也只把卡片抬到胸旁，虽然技术上有手部 IK，观众看不清“发动卡牌”的核心动作。

本轮重新编排玩家女生（俏皮兴奋）与 AI 男生（一本正经突然夸张）真正不同的表演：
- 抽牌：右手从胸前向下抓牌；左手稳住重心；
- 亮牌：真实右腕抬至肩以上展示精美实体卡画，卡片本体仍跟随真实 J_Bip_R_Hand 骨；
- 蓄力与出手：双臂展开、上身前倾、右臂向竞技场甩出，出现身体 follow-through 后收势；
- 命中反应：按真实引擎 HIT_HOST / SPELL_RESULT 向后退、摇头、手臂抬起自卫，不自动扣血；
- 胜负：真实 ASDC_R112_VICTORY 触发胜者欢呼跳跃双手高举，败者抱头弯腿懊恼；只有舞蹈时出现身体起跳，不是随机根节点飘浮；
- 闲时依各自独立人格做更频繁的调皮表演，而不是站定七八秒只轻轻晃肩。
- 尊重系统 reduced-motion，收敛大幅度动作，但保留真正的牌面与骨骼动作。

## 工程
- scene.mjs: DUELIST_POSE_SPEC 两套不同真实 VRM IK 手臂目标和强烈胸椎、颈椎、腿部受击与结果表演。
- hand-play-cards.mjs: 真人腕上实体卡牌亮相放大、面向观众、前冲甩牌及光泽，但腕跟随间隙仍 <11cm，画面真实卡牌内容源不变。

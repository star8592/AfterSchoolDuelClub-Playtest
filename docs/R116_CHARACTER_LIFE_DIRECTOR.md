# R116 · 放学后决斗社角色生活导演

## 核心
不是再给角色盲目加随机动作，而是让真实比赛事件决定每位角色在意什么、感受什么、接下来想做什么。

从单一动画池，升级为：合法比赛事件 → 角色个性与记忆 → 情绪、注意力、行为意图 → 已有真实骨骼和动画表现。

- 唯一规则源是 game.mjs / engine.mjs，绝不授予角色改牌、改 HP、改胜负权限。
- 全场统一接收已有真实事件：出牌、受击、比分与回合变化、挑衅/耳语、胜负。
- 14 种卡牌单位的性格预设：勇敢、外向、耐心、同理心。实例独立：同款不同人保留不同状态。
- 当前状态持续保留：紧张、自信、情绪、注意目标、比分领先/落后、最近受到的影响、动作冷却。
- 按性格和事件选行为；大事优先，闲聊不得覆盖出牌、命中、胜利群舞。
- 主角、所有已上场召唤单位、4 名真实高精度观众使用同一生活导演，彼此不共享个人情绪。
- M02 食堂大妈复用原 10 个真实动作中的愤怒跺脚、挠头、挥手、耸肩、欢呼等，不再只是站桩。
- 已有低声互怼现在更新双方注意力与情绪，不能未经录音就声称有真人或 Qwen 音轨。
- 全部离线、确定性、可复现；无新付费 API、无逐帧大模型，事件日志限长。

## 一个典型真实回合

食堂大妈进入赛场。她平时会叉腰关注对手或队友，不是在固定秒数播放一段循环。
有人突然出牌，她根据自己的性格决定是警惕、挑衅还是观察。
队友受击时，她会更紧张甚至恼火；对手却可能得意。
一个学生窃窃私语，另一个学生的注意力转过去，产生相应反应。
真实分数决定领先/落后心态；真实胜负触发不同阵营的庆祝与失落。
所有行为都建立在真实角色原来的 3D 模型与骨骼上，不新增低精度替身。

## 不变约束

1. 角色的心情是可审计的模拟变量，不是证明他们有真实意识。
2. 核心对战规则仍由唯一游戏引擎决定。
3. 不可接受的画面：T/A 形手臂、向背后转头、脚底漂移、手持道具离手。
4. 新增演员只有在身份一致、真实骨骼/表演、商用授权和 GPU 验收通过后方可加入。
5. 角色行为表演不能过度干扰玩家注意力，也不能把声音和文字混淆。
6. 复杂腿部 IK 和近景肢体表演依旧需要逐角色美术审查；模拟状态测试通过不代表电影级视觉验收通过。

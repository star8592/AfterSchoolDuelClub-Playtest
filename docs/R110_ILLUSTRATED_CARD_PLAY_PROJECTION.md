# R110 · 让60张插画真正进入三维对战

## 原始漏洞
玩家此前提出“卡牌有图片但打牌仍看不见”。R46时代的讲台卡牌投影还存在三个缺陷：
- 旧 ID 白名单只接收 E/G/T/M，40张 K/Q/S/P/X 新事件牌全部被拒绝。
- 旧模块只接收 event/unit 类型，但真实引擎的事件类型是 spell，导致全部事件牌无法正常在3D讲台显示。
- 旧卡牌投影在3D实体平面画星星/菱形，没有显示 R109 的60张独立插画，且镜头下尺寸过小。

## R110 已完成
- 真实出牌后，校验引擎 BY_ID 的 id、kind、name、cost、serial、side，不接受伪造或类型错误的事件。
- 左右三维决斗台的独立 Three.js 卡板改为真实绘制独有WebP图片的CanvasTexture，保持3D卡牌金属边缘与能量环。
- 只在实际出牌时加载这张照片，图片 Promise 缓存最多18条；每次切换贴图销毁旧GPU Texture。图片延迟不影响伤害和结算，旧图片加载完不会覆盖新卡。
- 主视角增加一张短暂展示的实际原画大图，玩家在桌面和手机上都能清晰辨认荒诞情节，名称/能量由真实HTML渲染。展示不阻挡操作，尊重减少动态效果的辅助设置。
- 游戏规则、3D镜头、人像朝向、声音默认开启及其他模型全部保持原样。

## 复核证据

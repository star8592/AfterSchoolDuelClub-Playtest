# R122 · 小朋友真正说话：原生 VRM 五种口型与 Qwen 录音同步

## 目标
在 R120 的夸张举牌、骨骼舞蹈和 R121 的真实五指握牌、喜怒哀乐形变之上，解决男/女主角只有真实音频、没有对应嘴部动作的问题。

## 已接入
- 两位高精源 VRM 的真实 A/I/U/E/O 五组口型，绝不使用贴纸嘴巴或低精替身；
- 录音只有在 HTMLAudioElement.play 真正开始播放后，才通过经过审核的 audio-engine.mjs 播放回执驱动人物嘴型；
- 播放暂停、真正结束、浏览器静音、别人抢话，全部发送去重的停止回执，立刻关闭对应人物的嘴部动作；
- 中文台词和已知的录音时长驱动近似逐音节开合，5 个源 viseme 按各自音节变化，每帧从源表情权重更新，不累积变形；
- 两名人物分别拥有独立音频序号和独立源 VRM 顶点，女主发言不会让男主同时张嘴；
- 有真实录音时启用额外的短暂面部近景，机位对准原骨架 J_Bip_C_Head，真实脸与上半身可见；
- 卡牌展示优先于说话镜头，胜负结算优先于说话镜头；远景体育馆持续保留，用户镜头可手动操控；
- PA 广播员不是任何一名主角，不能以主角嘴部动画冒充广播发声；
- 静音时字幕可以显示，但源面部不会假装录音正在播放。

## 实际限制
当前口型是录音播放时间和中文台词分段的近似嘴型编排，没有逐音素强制对齐，也没有从声波分析音高/振幅。未来需要做高质量强制对齐时应在本地离线完成并可控质量对比，不引入运行期云模型或额外 API 成本。

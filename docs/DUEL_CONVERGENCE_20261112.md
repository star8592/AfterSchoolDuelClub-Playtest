1. 20 张卡牌；M01 音乐老师、M02 食堂阿姨可合法抽到、花能量、上场；真实 12 个 GLB 和 2 个 VRM，共 14 种召唤实体。

3. 玩家获胜、AI 获胜、平局都显示有效的胜负和准确比分；一键再开局且 HP/卡牌/场景/能量重置；手机屏幕可操作。
4. R93 七种角色无 A/T pose，出场、攻击、命中、退回、原生动作、双阵营朝向与脚底贴地经过真实 Chrome GPU 检验。
5. GLB 发行清单检查真 glTF 二进制、真实网格/场景，最新模型与前版已打开页面的 URL 都是 HTTP 200；失效不能假称就绪。
6. 发布后**再**从公网执行 Chrome 验收。只有源分支验收不是正式发布证明。

## 统一研发工作流

任何并行实验都必须从最新 `origin/main` 派生短期 worktree，采用 `integration/*` 或 `feature/*`；重要新设计进此总账。研发可并行，但最终只能经统一主分支与统一 QA 发布；主版本每次合并前核对远端 SHA 和文件差异，避免互相覆盖。大规模旧 worktree 清理必须先审计 untracked Blender 源、QA 证据、授权文件，保留必要成果后再操作。未经比对不得删除。

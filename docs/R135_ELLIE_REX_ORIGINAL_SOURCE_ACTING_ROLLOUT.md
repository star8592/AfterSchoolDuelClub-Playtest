## 工程根因与资源选择

七名 Blender Studio 角色源高精骨骼在 R131-R133 的 QA 已证明带真权重、真腕指、真膝踝和可测鞋底，但普通正式默认仍是 R97 烘焙形变。单纯让 whole-model 整体晃动不能算真正全身表演。

研究开关 r135Pair=on 同时启用 E03、T04。r135Pair=E03 或 r135Pair=T04 可逐人独立预览，r135Pair=off 立即恢复默认 R97。没有第二套正式站点。G03 原 r134Jay=on 开关仍独立。

实际来源资源分别是 E03-Ellie-Skinned-R132-BakedRest-PILOT.glb、T04-Rex-Skinned-R132-BakedRest-PILOT.glb。原作者网格、材料、蒙皮权重均保留。

## 独立表演设计

- E03 加油队长：cheer-leap-whistle 性格。4.9秒独立循环待机，转头观察、双手鼓劲、前倾发力、受击失衡后恢复、兴奋庆祝。
- T04 守门人：heavy-door-block-wall 性格。6.7秒独立循环待机，稳重观察、肩胸压向对手、伸手拦截、受击后仰、重新稳定站姿。
- 真原始头颈、胸、脊柱、左右肩肘8条动画轨，配合 R129原始腿膝踝足趾8条动态轨，运行时每人16条。七段真实动画：Idle、Attack、Hit、Walk、Challenge、Worry、Celebrate。
- 真实肩/肘/腕世界向量每帧抽样，原本横展 T 字姿态由原带权重上臂的 FK 局部旋转纠正；不创造替身、假骨骼或虚拟顶点。
- 第二轮可见动作升级：E03 原始膝/踝骨骼轨道在研究开关下独立增强至1.50倍，实测带权重原腿顶点变化约0.030场景单位；攻击/庆祝叠加与真膝动作同步的有限腾空（庆祝高点不超过0.22场景单位），结束后恢复真实鞋底落地。T04 的原腿骨骼仅增强1.30倍，仍始终双脚稳重支撑、无腾空。原 R128/R129/R133 非本研究场景的轨道参数不变。
- R133 两只原始蒙皮鞋底作为严格接地依据，目标是角色面向对手、不穿地、不滑步。任何自动发生的后续“挑衅”小演出不属于无效复位。
- 始终保留源模型旧版及独立回退；M02、G03、两发牌主角和全部规则系统不被改变。

# R117: 真正由决斗者手腕握住的精美实牌

## 解决的体验问题
过去玩家打牌时，主角虽然做了动作，但漂亮卡牌主要出现在讲台外侧的光效投影上，看不到真实的手腕和精致牌面建立联系。R117 保留大号 R110 正式卡牌投影以便玩家阅读，同时新增一个从原始 VRM 右手腕位置跟随的精美实体卡。

## 实现
- scene/hand-play-cards.mjs：为两名互不共用骨骼的站台主角分别绑定 J_Bip_R_Hand。每帧 IK 更新后，采样右手真实世界坐标，只有有效的游戏卡牌事件才会显现对应道具。
- 使用已有 60 张 R109 精美插画，不是表情包、符号或图案占位。图像按出牌懒加载；两张手持卡、旧版讲台投影相互独立。
- 抽牌、展示和甩出阶段随原动作显示，2.63 秒后自动收起；图片异步回调按 serial 核验，旧牌不能覆盖新牌。
- 默认 2 个小型几何组合，不添加人物、不下载模型、不修改竞技规则与伤害。
- 玩家、对手各用自己的真实 VRM 腕部骨骼，不会出现卡牌从另一方手里冒出来。

## QA

- 请在最终公网手工审看卡牌比例、握持方向、镜头构图和动作节奏，不以程序检查代替美术验收。

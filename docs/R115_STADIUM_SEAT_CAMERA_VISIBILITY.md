# R115 体育馆看台座椅可见性修复

## 根因
之前体育馆虽有 396 个坐垫、靠背和支架网格，但 R114 正面截图仍像一排灰色板凳。
查源代码发现真实错误：正常 +Z 相机看到的远方 -Z 阶梯没有对应座椅，
因为 198 张 -Z 位置的座椅被放进默认隐藏的反向看台分组；
而默认可见分组的 198 张座椅实际摆在近端 +Z。靠背与坐垫的朝向也颠倒。

## 修复
- 普通视角在 -Z 真实显示 198 个完整座位，180° 后方视角显示 +Z 另 198 席。
- 坐垫在靠球场方向、靠背在靠后墙方向；恢复椅背真正面向体育场。
- 台阶防滑前缘和扶栏立柱跟随实物坐标改正。
- 不新增模型、座位数或 drawcall；保留完整体育馆结构和原有角色演出。
- 增加只读场景证据：stadiumSeatBanks 可显示实际坐垫/靠背世界坐标、可见性与数量。

## 测试
r45-duel/qa/browser-r115-seat-visibility.mjs：
- 桌面和竖屏前后各 198 席、可见性、面对方向、GPU 绘制数、资源无 404。
- 桌面/手机两组截图位于 r45-duel/qa/evidence/r115-seating。
- R113 原看台布局回归与 R116 角色生活模拟需要同时通过。

机器测试通过不等于近景美术完成：仍要从玩家视角复核细节及远景可读性。

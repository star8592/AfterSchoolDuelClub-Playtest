# R126 · 全部角色动作审计与统一主线施工记录

日期：2026-11-13。质量对照是 M02 食堂阿姨的天然夸张动作。模型加载、骨骼存在、动画播放回执不能代表“动作自然”的艺术验收。

## 逐一角色真相

实际审计 16 份源模型：2 位原始出牌主角、2 位 E01/G01 原 VRM、12 种召唤者。新增8名看台角色是复用原高精 GLB，并不是8个独立拥有全套手脚动作的新模型。

- HOST_PLAYER/HOST_AI：源 VRM 真实骨骼，内置源 clips=0；运行时 IK、五指、脸部形变、声音口型。必须继续强化身体重心、抛牌、胜负和独立性格。
- E01 铃声追不上、G01 橡皮筋建筑师：真实 VRM 骨骼，但内置 clips=0，靠运行时动作；需要独特的慌张/思考节奏。
- E02 纸飞机：5段源动画，无需人形骨骼；验证飞行、攻击、坠落和复位。
- E03 加油队长、E04 食堂接力员、G02 黑板密码专家、G03 实验学长、G04 社团总监、T03 默契收发员、T04 守门人：现行 R97 每人仅 Idle/Attack/Hit 三段 morph，默认可见 mesh 真实 Skin=0。无法产生持续完整腰肩肘、膝和脚踝独立行动，是“木棍感”的主因。
- M01 音乐老师：31真源骨骼、10可见皮肤网格，原始 Idle/Walk/Run 3段；此前 attack 演出错误退回 Idle。R126 新增加源关节的加法叠层：指挥、制止、惊吓、庆祝，附有真实关节检查。
- M02 食堂阿姨：10段原生真骨骼动画、720条原始动作通道，保留作为质量对照，不改动原模型与汤勺。
- T01 猫头鹰：129个实际网格、无原生骨骼绑定、0源动画。待补真正独立翼羽、头部和表情动作；不得用整个模型的摇晃冒充翅膀动作。
- T02 活体菜单：5段翻页等非人体动作，不需要套人类骨骼标准；需继续检查动作与情绪。

## 七名更高级原生蒙皮的阻碍

E03、E04、G02、G03、G04、T03、T04 已有 R119 实验模型，均拥有可见真实 SkinnedMesh，游戏运行时生成7类原骨骼动画（研究 GLB 本身没有源内置动画）。Z890 Chrome 36/36检查真正动作顶点通过，但它们的步伐、脚底接地、手部配合、脸部与原作者材质还未经过逐帧艺术验收。默认正式模型不可一键切成这些研发模型。

## 完整动作验收准则

每个人物必须独立检查登场、待机、攻击、受击、胜利、失败。每一段采用真实 3D 场景近景和手机窗口，分析预备、发力、碰撞、回弹、双足落地、回稳；手、眼、肩、腰、膝实际配合，并面向对手。必须保留零T/A建模手、零错误朝向、零脚滑、零回合规则双扣伤害、零动画残余。只有真实可见蒙皮关节的顶点运动或原形变通过技术核验，还需人为逐帧美术审查，才能声称改善自然度。

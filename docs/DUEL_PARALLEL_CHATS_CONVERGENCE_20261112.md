## 3. 统一后依次推进

1. **后续剧情引导（R98 候选）**：三段可实际点击的新手训练，基于现行 `engine.mjs` 单竞技场和真实手牌（不改写 20 卡规则），教学结束进入自由赛；PC/手机都要看到可操作的下一步。
2. **后续三维演出导演（R98 候选）**：对真实 `combo_effect` 实现“三镜头”：入场/喊招→技能物件运动→真实伤害、盾或抽牌结果；跳过只是跳动画，绝不跳数值；同一事件不得二次扣血。复用已上线的 3D GLB/VRM 和默认有声体系，不移植旧 CSS 主舞台。
3. **美术质量**：对两侧永久决斗者 + 14 个召唤实体逐一比对原画；尤其 M01/M02、低精度道具及 T/A 姿势；拒绝“能加载等于正式人物已定稿”的结论。
4. **冷加载质量**：保持真实 GLB 加载失败就绪门槛与一键恢复，检测首次 CDN 冷缓存的耗时、HTTP 404、模型体积、音频手势解锁。
5. **正式验收**：每轮先集成于最新主线 worktree，实际 Chrome 交互 + 模型/语音真实资源检查，通过后 PR 合到 `main`，再公网复核；只在本对话汇报。

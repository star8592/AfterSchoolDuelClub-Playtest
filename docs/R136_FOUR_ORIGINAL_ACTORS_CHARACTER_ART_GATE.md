## 为什么不能直接复制 E03/G03

七名真实原作者人物的骨骼结构各不相同。E04 原模型没有 DEF-Neck，胸椎和原胳膊属于较平的绑定；G02 使用 DEF-UpperArm_1 与 Forearm_1，真腿链在原作者 GLB 内已连接；G04 的裙装、靴子与侧肩要考虑蒙皮遮挡；T03 使用 DEF-Spine1/Spine3 与 DEF-Hand，真手/腿原导出存在分段层级，需要既有 R130/R131 源骨修复。强行同一骨骼模板会造成 T 字平举、手臂穿胸或脚乱动。

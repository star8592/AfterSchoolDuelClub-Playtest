# R123 看台道具连锁事故 · 工程与审计记录

## 定位

本模块是校园荒诞喜剧的纯表现层，不改变 engine.mjs、HP、护盾、召唤物 UID、出牌规则或胜负判定。R121 负责真实魔法命中，R122 以 17 张符合条件的真实法术事件驱动四种看台意外，R123 负责已有观众的道具、连锁动作、镜头以及广播配音。

## 连锁动作与人物模型真实性

1. 直接受波及者先躲，约 3.35 米内的真实邻座延迟 0.18 秒，较远学生延迟 0.43–0.53 秒。
2. 左右外端观众并非邻座，已纠正旧版把他们当作环状相邻的错误。
3. 模型 AnimationMixer 不代表一定有真实头部或手臂骨骼。浏览器实测原四位观众的 FK-Head 并未找到，所以绝不能宣传全部观众已完成逐关节骨骼表演。
4. 如有可访问的真实骨骼则叠加细微骨骼反应；缺少骨骼则使用已有 instantiateSummon.setCombatPose 做真实模型整体的后仰、侧倾、扭身，并保留其原始动画剪辑。QA 分别上报 animationMixers、boneDrivenActors、skinnedRealActors 和 authoredPoseFallbackActors。

## 正面观众特写

R122 的远看台画面中，人物过小不易看清。R123 在已验证的真正看台撞击之后，以自然平视方式缓动推近真实受惊观众与道具，再在约 2.75 秒后恢复双人决斗视角。没有改成俯视，也没有第二个渲染通道。

允许参数 r123Closeup=off 单独关闭特写；r122Crowd=off 关闭所有看台事故。若操作系统启用减少动态效果，或玩家主动将镜头旋转超过 45 度，不强制切入特写。

## 真实配音与误伤笑点

- R122 已有 8 条本地 Qwen3-TTS 学生受惊配音。
- R123 新增 4 条本地 Qwen3-TTS 广播配音，分别调侃爆米花、奶茶、作业与书包。
- 录音以 Opus 48 kHz 保存，每条保留准确原文、说话人、长度、SHA-256；实际音频播放才触发对应语音字幕。
- 真正观众误伤回执到达后，先播放受惊配音，约 3.5 秒后才排队播放广播；决斗者语音优先。比赛结算或换局不会让旧场次广播继续乱入。
- 人工试听与商业权利审查尚未完成。

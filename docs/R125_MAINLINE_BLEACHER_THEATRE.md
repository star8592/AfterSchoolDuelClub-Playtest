# R125 校园看台群体喜剧：最新版主线集成

## 功能边界和集成策略

R125 从现有 main 的 R124 镜头、原生表情、Qwen 嘴型、真实五指握牌、移动端阴影预算及 GLB 压缩传输代码起步。R122/R123 的魔法碰撞、观众、道具、音频通过适配层集成，不覆盖最新版 game.mjs、scene.mjs、audio-engine.mjs 的主线功能。旧 PR #106 已关闭但并非本次直接依赖；原 PR #109/#112 应与这个独立主线集成区分。

演出仅由规则引擎实际发出的法术结果驱动，不新增 HP、真实攻击范围或胜负规则。17 张攻击法术在确定性条件下触发四类无伤害观众误伤；QA force 参数从不作为生产默认。

## 8 名真实 GLB 观众，没有新假人

保留四个事故目标 E04（爆米花）、E03（奶茶）、G03（数学作业）、G04（书包），另把原来已加载的四个不重复角色 G02、T03、T04、M01 挂在看台。M01 为原始音乐老师角色，扮演纪律管理员，看到误伤之后打断，使用实际可用模型动画及整身姿态；任何不具备真实 FK 的逐关节动作都不会假装已完成。额外四名不另发起 GLB 网络请求，全部是预加载 12 个真实源模型的独立实例。

演员按真实看台 X 位置连锁躲闪；右后侧原生 M01 约 0.43s 后开始制止。正式模型虽有可播放动画 mixer，但不代表全部拥有逐关节手臂和头部骨骼，QA 持续区分真骨骼、mesh 和主体姿态 fallback。

老师座位旁增加固定在看台栏杆上的 3D 纪律牌，画面文字为「观众席不是靶子」「听老师的！」，仅在实际事故时出现，随事故结束隐藏。它是场馆物件，不冒充老师握在未绑定的手中。

## 两次主镜头切换

真正魔法接触看台 → 学生近景展示躲闪、爆米花及文具乱飞 → 切到真实 M01 音乐老师出面阻止 → 恢复 R124 正面双人决斗主视角。全部使用已有主摄像机的世界空间位置和 lookAt，额外渲染通道为 0。允许 r123Closeup=off 仅关闭特写，r122Crowd=off 关闭整条看台意外；系统减少动态效果以及用户手动偏航角度超过 45 度时不强制切镜头。

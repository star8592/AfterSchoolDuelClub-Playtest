# R118：Jay 真正可见的骨骼动画试验——修复旧版误判

## 审计结果

原始制作仓库里同时保留了：
- 正式 G03-Jay-Landing-R97.glb：22 个可见网格，0 个可见 SkinnedMesh，
  3 段基于 Blender 原始骨骼烘焙的高质量身体形变。面部细节及踏步着地动画正式保留。
- 已有的 G03-Jay-Skinned-R86.glb：16 个可见 SkinnedMesh，
  含真正的蒙皮权重和可操控的骨架（浏览器实际引用约 286 条骨骼），
  原文件没有动画片段。文件大小约 4.3 MB，未新增第三方模型。

过去 R86 动画控制器把 Blender 骨骼名称 DEF-Shoulder.L/R 错写为
DEF-ShoulderL/R，又没有考虑 GLTFLoader 对节点名的规范化处理，
导致动画控制器找不到肩骨、输出零条运动轨道。这不是模型没有骨骼，
而是绑定代码没有匹配到真实骨骼。

## 修正
- 对真正可见的 source SkinnedMesh 所用骨骼，使用规范化的节点名称搜索，
  恢复左右 Shoulder 的真实控制。
- UUID 精准绑定动画四元数轨道，解决带小数点的骨骼名称错误解析。
- 真实蒙皮对应的角色状态层按 source 骨骼节点结构映射到 Head/Neck/Chest/
  UpperArm/Forearm；原动画攻击/受击有更高优先级，微动作不会复位正在攻击的关节。
- **仅在现有 g03Study=rig 研究开关启用**；普通玩家仍用正式 R97 模型。
  不引入低模、不强制切换、无需新增下载来源。
- 与独立 R116 个人行为状态共享注意力、自信、紧张、挑战/观察意图。

## 真实 GPU Chrome 验收
运行 qa/browser-r118-jay-true-skin.mjs，桌面+竖屏分别检查研究与正式两版：
- 研究版实际 G03 来源匹配，运行时有大量真正可见 SkinnedMesh 关联骨架；
- 动画 Mixer 确实播放自行绑定的 R86_Skeletal_Idle；
- 角色状态层逐帧写入真骨骼的四元数，活动幅度受限；
- 官方默认 R97 仍然保持 original morph mode，不伪称为实时骨骼；
- 两版本在真实体育馆里都保持面向对手，没有失去 3D 场景与模型；
- 真实四种截图在 qa/evidence/r118-jay。

## 尚未完成
目前这**只是 G03 的可回退技术试验**，还不是七名 Blender Studio
正式人物全体重新蒙皮。R97 多段着地动画、画面材质与脚底效果不能因
试验的肩部动画被粗暴替换。后续应重建完整有权重的单场景真骨骼
Blender Studio 高精模型，再由人工比较近景，测试全部通过方能切正式。

本地已发现 Jay 与 Rex 的可编辑源工程，但其他五名角色的源文件仍需
取得合适授权并重建。R117 的高品质形变版本继续作为稳妥正式保底。

# R120 · 男女决斗者边打边讲 · 三回合入门教程

## 面向玩家的一分钟规则（正式自由赛）

1. **获胜：** 你与 AI 各有 **20 点人气**。先把对方的人气打到 0 就赢；双方对战至 12 回合仍不分胜负时，比剩余人气，相等为平局。
2. **选牌出牌：** 每张牌右上角的数字是能量费用。点击手牌，再按下方金色「出牌」。同一回合只要能量足够可连续出多张。
3. **两种牌：** 人物牌真实召唤 3D 队友；事件牌马上生效（伤害、回复、抽牌、加成等）。
4. **人物何时攻击：** 刚上场待命，下一次轮到自己、按「结束回合」后自动攻击。先打对方上场人物，双方可能互相反击；没有对方守卫时才直接扣对手人气。
5. **进阶：** 同一回合打出两种不同风格，可能触发一次连携；活力克创意、创意克默契、默契克活力。完整图鉴有 60 种卡，每局主题卡组 40 张。

这份规则始终可从界面顶部的 **「一分钟规则」** 展开；大段资产许可证不再混在玩法规则里，另设「素材鸣谢」。

## 为什么要增设实战教程

旧版三个可玩的剧情教学首先讲「粉笔弹射 / 广播室串台 / 招新海报护盾」，玩家可能学会连携却不了解出牌、攻击、反击和胜利条件。**旧的三关仍保留为「进阶 · 三关连携试炼」**；本轮新设 `?mode=guided` 三回合实战教学，入口标为「新手必玩 · 男女对打教学」。

## 三回合真正演示：不是假视频

新入口仍然装载正式 3D 体育馆、16/16 真正模型，使用原始 `engine.mjs` 的出牌和伤害规则。**教学采用明确披露的缩短赛：己方 20 点人气，男决斗者作为陪练的初始人气只有 6 点；正式自由对战仍是 20:20。** 两张事件牌、AI 两张人物牌都取自原本 40 张卡组的实际牌池，而不是捏造的幽灵牌。

| 回合 | 玩家实操 | 对手真实回应 | 玩家学到什么 |
|---|---|---|---|
| 1 | 选 `E01 铃声追不上`，花 1 能量，召唤人物，结束回合 | 男决斗者打 `G01 橡皮筋建筑师` | 如何选牌、召唤、人物待命、结束回合、AI 回应 |
| 2 | 3 能量打 `E06 飞来的巨大黑板擦`，立即扣男方 3 点人气，从 6 到 3，结束回合 | E01 / G01 依据原引擎真实互相攻击与反击，男方打 `T01 迟到的播音员` | 事件牌立即生效、人物下个回合自动攻击、守卫挡攻击与反伤 |
| 3 | 再打第二张真实 `E06`，对手人气从 3 降到 0 | 男决斗者祝贺并邀请自由对战 | 目标是让对手人气归零，亲自完成真正的胜利判定 |

玩家不需要手动控制 3D 人物的四肢；他只需依次点击高亮卡牌、金色出牌按钮、结束回合。在演示期间出牌控件会等待语音解说结束，避免一口气点完而听不清。初次载入有一个明确的「开始声画教学」按钮用于满足浏览器自动播放策略，**没有独立的“先去开启声音”额外门槛**。

## 14 段男女原创 Qwen3 语音 + 始终可看的文字

- 本项目已有真实角色声线：女决斗者 **Serena**、男决斗者 **Dylan**。
- 使用 Z890 缓存的 `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice` 离线生成 14 段原创 Mandarin 语音。**9 段女声、5 段男声**，共 **688,172 bytes**，全套 Opus `.ogg`；无需游戏运行时联网请求生成服务、无需付费 API、也不冒用真人原声。
- 每段录音的 `tutorial-manifest.json` 包含真实文件路径、准确字幕文本、说话人、音频秒数、SHA-256、人工试听状态。`qa/check-r120-guided-voices.mjs` 与 `qa/generate-r120-guided-voices.py` 可核对和重建。
- 声音随真实出牌/结束回合/反击/胜利阶段切换，由现有 `audio-engine.mjs` 的单声道语音队列负责播放，不同时串入普通角色战吼。背景音乐在讲解时自动 duck，不改变原声音默认开启、静音偏好及浏览器用户手势政策。
- 文字同时显示在 3D 场馆上的「女决斗者 / 男决斗者」专用讲解框，保持原文可读；有「重听这句话」和「退出教学」。静音或播放失败时仍显示规则与操作文本，**不声称播放了没有实际音频的语音**。
- **人工逐条试听尚未验收**：所有条目的 `review_status` = `pending-human-listening`，正式商业版本应继续检查声线自然度和 Qwen 模型的商业许可边界，不伪称已完成这项审核。

## 安全与回退

- 全部规则变更局限于一个新的训练专用状态 `guided`。正式 60 张卡、6 套主题牌组、20 人气与 AI 战斗引擎不变；旧 3 个可玩剧情关卡亦未删除。
- 只添加少量 Opus 音频到 GitHub Pages，无在线转录、语音 API 密钥、用户上传或新增遥测。3D 角色资产数量与高精度不下降。
- 如果需要回退，一次性回退 `guided-tutorial.mjs`、UI、音频引擎路由、音频素材和对应文档；旧模式 `?mode=tutorial` 与正常自由对战依旧独立。
- 生产合并后必须检查 GitHub Pages 真正完成 build，并从公网浏览器验证桌面、竖屏、**男女两位真实播放**、3 回合规则胜利、规则文字和旧玩法回归。

# R106 · 真正的眼睛朝向（修复 R105 假通过）

用户公网截图明确证明 R105 我方/AI 和召唤的 VRM 模型是背向对手的。
根因：R105 将 VRM 源模型的正面假定为局部 +Z，真实 VRM 眼球/睫毛/嘴巴的局部 z 坐标均比脸后侧更负，人物真正的正面为 -Z。

## 修复
- 校正 E01/G01 真实 VRM 轴为 Math.PI，保留不同 GLB 的原始轴，不对所有模型统一旋转。
- 两位独立站台出牌者同样由 E01/G01 源身份驱动，因此自然获得真实脸朝向对方的修正。
- 测试不再用同一朝向补偿表自证。独立读取 Shino、Fumiriya、Host_Female、Host_Male 四个 VRM 的 EyeIris 与 Face Skin 原始三角形顶点，确证眼睛朝 -Z。浏览器再以独立真实正脸轴和世界旋转计算真正的 facing dot。
- 增加负控：旧 R105 实际背向旋转在新测试中 dot=-1 必须失败。

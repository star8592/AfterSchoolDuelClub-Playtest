# R125 看台学生喊叫与体育馆广播：首局慢网可靠性修复

## 用户可见问题
R124 已正式合入 main，GitHub Pages 的 scene、game、audio-engine 文件及原创音频经 SHA-256 核对与 main 一致。公网 Chrome 首局可以实际出牌、计算 HP、生成看台 3D 道具抛飞、播放学生喊叫，但原 R123 设定 3.5 秒固定定时器的校广播常出现等待超时，不能把资源 HTTP 200 误报为全部实际播放。

## 改动
- 游戏侧于经过 canonical engine 校验的 R122 真实看台事故回执到达时立即向语音引擎提交该件道具对应的体育馆广播，不再等待一个可能失效的固定 3.5 秒 timer。
- 音频侧为已验证事故增加短期临时队列，在首次网络加载声源清单较慢/ AudioContext 用户手势正在解锁时保留至多一段学生喊叫和一段校园广播，音源就绪后补齐；逾期丢弃，避免下一局误播放。
- 广播只有在对战主角语音和观众实际喊叫均结束后开始；依赖 HTMLAudioElement 实际 ended/error 回调而非猜测的固定秒数，绝不冒充未播出的语音字幕。
- 换局、教学切章、游戏胜负结算和用户显式静音均删除临时事件且前移 epoch，禁止旧声音穿越到新一局。正常播放、默认开声及用户声音滑杆遵循旧版行为。
- audio.status 报告 bleacherDeferred，给 QA 提供可证实的首局延时状态。

## 真实验收
独立 Z890 服务器 127.0.0.1:11285 的监听 PID 与工作目录已核实。正常桌面/竖屏 R123 看台 30/30、R122 误伤 18/18、R123 换关静音 12/12 全通过；R120 真实三回合男女声教学桌面、手机及男女原声实播均通过；R124 真实 VRM、十五五指、15 元素、高清卡面/战斗声音/帧率 18/18，通过门槛最高绘制调用 860。

新增专门模拟：故意让原始 Qwen3 广播 manifest 网络响应延迟 8.5 秒，在角色和卡牌先加载完毕时立即按 K01 正式出牌。普通模式下验证首轮喊叫和广播晚到但都真实播放，且语音次序为学生先、广播后。第二场在 manifest 解锁前点真实静音按钮，验证延迟事件全部取消、不能补播。browser-r125-delayed-bleacher-audio.mjs 共 13/13 通过，无 JS 或 HTTP 错误。

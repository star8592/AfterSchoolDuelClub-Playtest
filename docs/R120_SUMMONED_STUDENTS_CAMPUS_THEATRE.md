# R120 校园荒诞喜剧：召唤人物有各自夸张的舞台表演

## 不再温文尔雅同一套动作
本项目的核心不是两个静止的发牌人围着几张卡，也不是 12 个拥有同样摆动幅度的精美摆件。
R120 在已有 E01/G01 VRM + 12 个高精度 GLB/生物/物体召唤角色上进一步实施了表演编排：

每次真实卡牌召唤仍然以引擎原卡牌、原格子、真实玩家 ID 与 serial 为唯一权威，视觉层仅触发对应角色表演，三幕结构为**蓄力 / 激烈登场 / 收势回原姿态**。
人物在真实动画与源骨骼上调整身体姿态、转身幅度、蓄力节奏及跳跃幅度，不添加取巧低多边形人体/替代骨骼，也不改变实际伤害。

身份样式 12 种，各自独立：
- E02 纸飞机陀螺旋转；
- E03 加油队长双臂高举欢呼；
- E04 食堂接力员冲刺；
- G02 黑板密码专家表演板书魔法；
- G03 实验学长实验炸锅式亮相；
- G04 学生会总监发布命令；
- M01 音乐老师挥臂指挥；
- M02 食堂阿姨握原来真正骨骼控制的锅铲招呼；
- T01 猫头鹰播报新闻抢麦；
- T02 食堂活菜单翻页；
- T03 收发员迅速传递；
- T04 活动室守门人夸张拦路。
原有 E01/G01 的召唤单位继续使用绑定实骨骼独立人格，但与两位正式发牌主角完全独立，不把一个人贴两次。

## 伤害、胜负和脚底
- 受法术击中：真实格子存活对象播放原有 Hit_Recoil / 骨骼动作，另外大幅度后仰和后退；0.73 秒逐帧平滑归位，不留永久偏移。
- 获胜：原有五段舞蹈继续执行；胜利方可追加原来源体形变的胜利大动作，静态无踝骨高质量角色只在 stomp 和 final_pose 期间轻跳再落地。
- 失败：受击后萎缩、恢复原姿态。没有指向实际被击中的对象时绝不凭空制作命中视觉。
- M02 源攻击动画会让实际脚踝漂移约 33cm，不能用于脚底接地庆祝；改回原源 idle 加现有肩骨/锅铲 Victory 舞步后 R114 脚底验收恢复通过。
- 所有非默认模型继续按原版手感加载，R119 真蒙皮研究开关仍保持隔离，不强行替换已正式高精角色。

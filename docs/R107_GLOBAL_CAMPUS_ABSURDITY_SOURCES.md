# 《放学后决斗社》R107：古今中外校园荒诞奇闻素材研究
2026-11-13。研究对象：真实学校事件、学校公布的非典型传统、古代文献里的谐趣叙事及游戏原创故事。
这是一份独立原创的**卡牌游戏素材库**，不是新闻报道。真实事件只取核心喜剧机制，角色、卡牌画面、文案、玩法重写。

## 证据分级
- A：学校、博物馆、大学馆藏、出版社、经典文献研究等第一手或权威资料；可以写“有记载”，未必支持民间夸张细节。
- B：知名媒体实地采访/报道或学校转载媒体；可以写“媒体曾报道/采访”。
- C：古代笑话书、笔记、文学轶事；作为**文本中的故事**，不能当成“真实发生的校园事故”。
- O：原创二次想象，例如茄子炒香蕉、会写检讨的橡皮；不得声称发生于现实学校。
- 安全与版权：禁止模仿高处攀爬、破坏公物等危险恶作剧；不照搬商业美术、人物、节目段子或未授权摄影。

# R114 · Real students in the sports-gallery audience

- Four distinct, **preloaded high-quality** Blender Studio animated GLBs
  E04 / E03 / G03 / G04 are cloned into dedicated student spectator slots.
  Two occupy accessible front bleacher sections, two the rear top step;
  none is an independently invented low-poly standee or an extra download.
- Existing real bone animation mixers continue to animate the source models.
  Subtle spectator wave is rendered through source FK shoulder controls
  plus torso/head root sway, reset each frame to prevent cumulative distortion.
- Card-play events cause applause; real hits cause shock; a winner event
  causes one side to cheer and the other to give a restrained sympathetic
  response. Reduced-motion preference suppresses exaggerated movement.
- The renderer updates four spectator models; never mutates HP or board.
  Front/rear stadium, 396 chairs, actual VRM duelists and 60-card rules
  remain from main. Audience is an artistic pilot with four students, NOT
  an already finished full spectator crowd.
- Explicit browser evidence: desktop + phone R114 14/14, R112 20/20.
  drawCalls under 1200 in the tested views, with genuine GPU Chrome.
- File paths: scene/stadium-audience.mjs and stadium-crowd-motion.mjs,
  qa/evidence/r114-crowd.
